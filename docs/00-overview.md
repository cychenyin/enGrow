# 简介

## 是什么?

enGrow 是一款英语学习的桌面软件. 提供以下价值: 
1. 通过情景记忆法辅助英语基础词汇学习 
2. 通过知识图谱辅助英语词汇突破 
3. 通过英语词汇精解辅助词汇进阶 
4. 集成学习方法《如何组织规划系统性学习》，《英语构词解析记忆法》
5. 英语语法学习功能(开发中, 敬请期待)

## 给谁用? 

1. 以通过英语考试为目的掌握词,语法, 听, 说, 写
英语考试包括: 

| 缩写 | 考试 |
| ------ | ------- |
| JS     | 初中      |
| HS     | 高中      |
| CE     | 大学      |
| CET4   | 四级      |
| CET6   | 六级      |
| ETP    | 考研      |
| GMAT   | MBA入学考试 |
| GRE    | 美国考研    |
| GE     | 中国研究生英语 |
| EED    | 中国考博    |
| IELTS  | 雅思      |
| TOEFL  | 托福      |
| TEM4   | 专4      |
| TEM4   | 专8      |

2. 英语持续学习者, 以在领域中掌握英语的听,说,写应用能力
3. 教培从业者: 意图提升英语教学效果, 提升商誉和营收的教培从业者可使用本软件作为工具进行授课

## 功能简介

1. 使用情境记忆法基于考试大纲,考试核心词的词汇积累
2. 使用知识图谱, 扩展词汇量
3. 使用词汇精解深入掌握词汇
4. 使用构词解析工具练习构词解析记忆法
5. 单词听写工具
6. 语法学习工具(开发中)
