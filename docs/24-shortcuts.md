# 快捷键速查表

## 全局快捷键（任意面板生效）

| 快捷键 | 功能 |
|---|---|
| `Ctrl+O` | 打开视频文件 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+Q` | 退出程序 |
| `F11` | 全屏/退出全屏 |

---

## 视频播放

| 快捷键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `→` | 快进 5 秒 |
| `←` | 快退 5 秒 |
| `Shift+→` | 快进 30 秒 |
| `Shift+←` | 快退 30 秒 |
| `A` | 跳转到上一条字幕 |
| `D` | 跳转到下一条字幕 |
| `R` | 重播当前字幕 |
| `↑` | 增大音量 |
| `↓` | 减小音量 |
| `M` | 静音/取消静音 |
| `F` | 全屏/退出全屏 |
| `[` | 设置 AB 循环 A 点 |
| `]` | 设置 AB 循环 B 点 |

---

## 词汇标记（词汇面板中选中单词后）

| 快捷键 | 功能 |
|---|---|
| `N` | 标记为生词（未掌握）|
| `P` | 标记为熟词（已掌握）|
| `C` | 收录到定制词表 |
| `Enter` | 查词典 / 跳转到单词出现时间点 |
| `Delete` | 从当前列表删除 |
| `Ctrl+F` | 搜索单词 |
| `Ctrl+A` | 全选 |

---

## 听写模式

| 快捷键 | 功能 |
|---|---|
| `Enter` | 提交答案 |
| `R` | 重播当前词发音 |
| `Esc` | 跳过当前词 |

---

## 知识图谱面板

| 快捷键 | 功能 |
|---|---|
| `N` | 选中节点标记为生词 |
| `P` | 选中节点标记为熟词 |
| 鼠标滚轮 | 图谱缩放 |
| 鼠标拖拽 | 移动图谱视野 |
| 双击节点 | 以该词为中心展开子图 |

---

## 词典面板

| 快捷键 | 功能 |
|---|---|
| `Ctrl+F` / `Ctrl+D` | 聚焦词典搜索框 |
| `Enter` | 执行查词 |
| `Alt+P` | 播放当前词发音 |
